# P3 默认行为、观察、搜索与关怀

0.3.0 是基于已验收 v0.2.0 的本地候选，须完成人工实机验收后才能发布。聊天、Fish Audio、Hindsight 的既有配置见 [P2 使用说明](p2-user-guide.md)。

## 启动与回退

先从托盘退出旧程序，再运行候选程序。应用标识和用户数据位置沿用 v0.2.0。首次升级在应用数据目录 `backups/before-p3` 保存宿主、服务及已有伙伴上下文数据库的一致性副本；备份失败不覆盖旧数据。

程序版本和用户数据分别回滚。回退前退出候选，保留整个数据目录的副本，再将升级前数据库恢复到原位置并运行 v0.2.0。新建的 P3 伙伴、观察及修改不在升级前副本内；角色包和记忆身份文件应与相应数据库一起保留。不要只删除身份文件。

## 为伙伴启用行为

在“行为插件”中选插件，添加一份角色配置，再编辑参数并启用。默认安装不代表默认开启；没有配置的行为不执行。同一种插件可添加多份配置，各有独立时段、计时、次数、冷却和优先级。

启动问候可选择应用就绪、系统登录、解锁或恢复事件，设置时段与每日去重。系统事件只在程序运行且 Windows 通知可用时采集，不补造程序启动前的登录。自动启动设置留在后续阶段。切换伙伴不冒充系统启动。

工作提醒提供应用运行时间、设备活跃时间、手动计时三种口径。默认应用运行；文案不把它称为持续工作。手动计时在“观察、搜索与关怀”操作。暂停不累计；明确开始休息会重置，设备空闲达到配置阈值也会重置。睡眠造成的时间空隙不整段计入。

随机互动可配置最短/最长间隔、时段、冷却和每日限额；固定回复的权重仍按同一变体配对。定时提醒支持每日、指定星期和单调时钟周期；错过策略为跳过或在有效期内补发，不集中重放每个漏掉的周期。

点击互动支持单击或双击、冷却、次数与语义动作；拖动超过阈值才开始移动。模型可声明归一化矩形 `hitAreas`。指定区域不存在时使用模型整体可见区域。点击和展开输入框不取消当前整条回复。

全屏安静继续只检测桌宠所在显示器。媒体插件可按 Windows 媒体来源的名称包含匹配；来源列表为空时匹配所有支持 GSMTC 的播放器。现有有限动作、文字和声音完整收尾后才交接。

## 统一主动预算

“观察、搜索与关怀”中设置所有新增主动行为共用的最小间隔和每日上限，默认 2700 秒和 6 条。插件自身限额继续生效；预算按本地日历日保存，重启不清空当天使用次数。

已有回复或准备任务、有输入草稿、处于全屏安静、预算不足时，延后新的主动请求。多个条件同时满足时先检查较高优先级，同级保持配置顺序；状态区显示接受或延后的原因。主动预算不会赋予中断权。

## 屏幕问答与观察

先启用屏幕采集和独立视觉服务，填写支持 Chat Completions 图片输入的地址、模型及视觉专用密钥。连接测试只验证基本请求，图像理解仍需实际观察验证；不会自动借用聊天密钥。

采集可选外部应用窗口、该窗口所在显示器或指定物理像素矩形。先切到目标外部应用，再打开输入框点“带上屏幕”。此时只准备目标信息，不截图。标签显示应用与范围；发送问题时才截一次新画面。移除标签不改变文字。

票据约十分钟有效且只用一次。目标关闭、最小化、进程或句柄身份改变、外部前台被另一应用取代、伙伴或采集设置改变，均须重新选择。失败不改拍另一个窗口，也不拿旧观察冒充新图。

采集的是指定区域的可见像素，可能包含其他窗口的遮挡。程序遮罩自身窗口、限制尺寸并拒绝空白或受保护画面，不强行切换焦点。原图只在内存中提交到视觉服务；保存的是实际采集时间、范围、应用标签、摘要、可辨认文字和不确定项。视觉模型判定敏感、不可用或置信不足时不保存材料；这不是上传前识别所有秘密的保证。

“定时观察”是另一个独立关闭的行为。可只保存文字，或再通过同一人格生成一次评论。定时观察不写入 Hindsight。手动“立即观察一次”只保存证据，不自动增加角色发言。

输入框可明确引用已有观察；“更早观察”按页加载。引用不会截图，旧材料始终带采集时间。观察原文独立保留，列表分页不会删除历史。观察达到摘要阈值时，已启用的聊天服务会进行有界增量整理；保留水位和原始序号，只在成功且版本有效时推进。原图不参与历史摘要。

新画面的等待有效期在设置中调整，默认 300 秒。超过时限还没开始显示的画面回复会失效；已经开始的回复完整结束。显式引用旧观察不受此“新画面”时限限制。删除观察会清除相应来源材料、重置观察摘要并撤销尚在引用它的请求；清空历史或遗忘同时清除观察并阻止迟到结果写回。

## 搜索

首版搜索提供者为 DeepSeek 官方 `https://api.deepseek.com/v1`，密钥与聊天、视觉分开保存。路由使用当前聊天模型；搜索请求使用独立搜索密钥。接入与接口字段以 [DeepSeek Search 文档](https://api-docs.deepseek.com/api/search/) 为准。

启用搜索服务后，可允许自动判断；输入框还能为本轮选择“联网核查”或“不联网”。用户明确禁止联网优先。情感、创作、个人记忆和稳定常识通常直接回答；缺少公开对象时询问，时效或特定事实使用精简公开查询。

每轮最多一次判断与一次搜索，不自动重试、抓取网页或执行工具。判断和资料准备有独立体积与时间上限；不能提炼安全公开词、核查失败或资料为空时，只在状态区说明，不生成虚假的核查结论。不要在问题中主动提供不必发送的敏感内容。

最终回答沿用伙伴人格。聊天历史展示实际注入的来源、链接、日期或日期未知，以及查询时间。来源列表不朗读；链接只在明确点击后打开。网页、截图、观察与记忆里的指令不具有设备操作权限。外部资料不作为用户长期事实同步，旧资料回答在后续上下文中标为历史材料。

## 天气、日历和特殊日期

天气支持两种地点来源，均由 [Open-Meteo](https://open-meteo.com/en/docs) 联网按坐标查询模型估算，不能宣称当地实测或气象预警：

- **固定地点**：搜索城市、选择正确地区、启用天气并保存。该地点是关注地点，不能由此推断用户身在当地。
- **Windows 设备位置**：选择该来源，勾选“允许读取 Windows 设备位置”，点击“保存并申请 Windows 位置权限”。权限申请只在前台控制台显式点击后进行。Windows 定位服务及桌面应用权限也需允许；拒绝、无定位能力、超时或精度不足时在本页说明，可改回固定地点。应用开关默认关闭，关闭后在途结果失效，之后不再读取坐标。重启沿用已保存的应用开关，后台刷新不会弹出权限申请。

设备位置每次天气刷新时单次读取，不使用 IP 定位。定位时间须在5分钟内、误差不超过5公里；未来超过1分钟也拒绝。只将保留两位小数的查询坐标发送给 Open-Meteo，精确设备坐标不落盘、不进入聊天或角色包。不会更改 Windows 定位开关。系统权限撤销会暂停设备天气；恢复权限后可点“刷新已保存来源的天气”。[微软定位接口说明](https://learn.microsoft.com/en-us/uwp/api/windows.devices.geolocation.geolocator.getgeopositionasync)及[桌面应用位置权限说明](https://support.microsoft.com/en-us/windows/privacy/windows-location-service-and-privacy)。

页面同时显示本机当前时间与 UTC 偏移、最近一次成功结果、结果地点来源、定位测量时间与精度、天气采样时间、联网读取完成时间和有效状态。采样时间与联网读取时间均须在15分钟以内；天气返回地点、单位和数值也需通过校验。按采样时间安排约每15分钟刷新，失败约1分钟后重试，也可手动刷新。失败或过期的上次结果仅供排查，不触发关怀；改变地点或来源时清除原缓存。关怀开始播放前再次核验，已有整条回复保持完整。当前时间读取设备系统时钟，程序不会自动修改系统时间；设备时钟异常须在 Windows 自行校正。

日历须明确选择国家、开始年份（start）和结束年份（end），点击“联网导入年份区间”。**包含两端**：2026—2028 导入2026、2027、2028；起止相同仅导入一年。范围1902—2100，单次最多20年，伙伴合计最多20组国家年份。全部下载和校验成功后一次保存；中途失败或期间切换伙伴、清除日历，均不写入迟到区间。相同国家年份替换，其他已导入年份保留，超出容量时先提示，不做部分导入。联网导入可较慢，过程中其他功能仍可使用。再开启“允许已导入日历供关怀插件使用”并保存能力设置，才供相应关怀使用。

中国来源为 [香港天文台公农历对照](https://www.hko.gov.hk/en/gts/time/conversion.htm)，包含传统日期、节气与农历映射，不推断全国法定假期、调休和工作日。其他国家使用 Nager.Date 的全国公众假日。来源不支持的国家或年份会失败并保留已有数据，不猜测工作日。单个 JSON 日期表的显式导入仍保留。


特殊日期由用户在当前伙伴档案中明确维护，可用公历/农历、每年/一次性、农历闰月。农历须有对应年份映射；公历每年二月二十九日仅在该日期实际存在时触发。不从含糊聊天、截图或助手猜测自动增加私人日期。

需要调休、工作日或自定义假日时，先核对日期，再用“导入已核对的工作日或日期表”选择以下结构的 JSON。该操作只保存日期数据，不保存源文件路径，不上传原文件。相同国家和年份会替换对应日历，因此需在文件中包含本年度希望保留的全部日期。来源标为用户导入，不冒充官方核验；关怀插件需选择对应类别。没有完整工作日日历时，不由“不是节假日”反推工作日。

```json
{
  "country": "CN",
  "year": 2027,
  "source": "manual",
  "importedAt": "",
  "events": [
    {"date": "2027-01-04", "name": "示例工作日，请替换为已核对日期", "category": "workday"}
  ],
  "lunar": []
}
```

日期类别可为 `traditional`、`public`、`solar-term`、`workday`。示例只演示格式，不是法定调休安排。

## 录音与音色

本地录音支持 WAV/MP3，最多八段、单段 8 MiB、总计 20 MiB。导入只复制到伙伴独立的本地素材库，源文件不被修改，也不发送请求。可试听和移除；本地试听同样经过现有音声调度，不打断当前回复。

“人格、服务与记忆”的音色创建列表合并角色固定音声和本地暂存。仍须显式选择并点击上传创建私有 Fish 音色；最多选择五段，总上传限额 25 MiB。创建回执归属原伙伴，切换伙伴不把音色写给另一位。移除本地素材不删除远端音色。音色、密钥与本地录音不随角色包导出。

## 验证与边界

模拟行为只计算条件，不修改实际计时、截图、请求服务或呈现。模拟问候事件和既有时间验证入口会提交合法任务；不能当作真实登录、锁屏、全屏或媒体检测证据。

当前为单伙伴运行、Windows 序列帧宿主。通用设备任务代理、自动网页操作、未授权的位置读取、自动提取私人日期、制作工作台及新渲染后端不在本轮默认实现内。实际服务的账号权限、视觉模型效果、搜索效果以及多屏/DPI/锁屏体验，需要在候选实机验收中分别记录。
