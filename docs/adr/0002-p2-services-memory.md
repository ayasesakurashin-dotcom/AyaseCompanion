# ADR 0002：P2 统一回复、服务与实例记忆

状态：P2 功能及呈现优化均已实机验收通过，正式基线为 v0.2.0，协议沿用 1.x 的向后兼容扩展。

## 统一回复和呈现

角色实例保存角色称呼、用户称呼、人格、回复语言、音色、朗读语言及发送策略；包内人格为初始推荐值，本地修改独立保存。聊天与插件生成回复共用 CharacterReplyService 的人格组织入口，翻译和摘要使用独立内部提示词。

Rust 接受请求时固定实例、人格修订、历史代次和取消令牌。生成准备不占用呈现锁，同一实例的生成任务保留接受顺序；开始授权前再次核对人格与历史，已经开始的回复继续使用原快照。默认新消息等待当前整条回复，用户可明确改为停止当前回复。

聊天适配 OpenAI 兼容 Chat Completions SSE，只读取正文 content，忽略 reasoning 和 tool_calls，并过滤跨片段的 think 标记。正文、事件、输出和缓存均有限额；流中断保留已收到的正文，按失败收尾，不用固定后备替换已经显示的内容。无正文时，只有 generated-with-fallback 的明确后备才能接替。

文字优先策略在模型正文接收完毕、可读化后竞争呈现授权；语音同步策略额外等待全部音声准备结束或语音降级。气泡使用完整正文测量分页，再按本地动画速度显现，最后一页读完后关闭。网络流边界不决定页面或语音分段。音声按完整可读正文切段、并发准备，全部结果结算后在一个 Web Audio 上下文内预解码并顺序播放，段间不再重新请求或解码。文字、音声和有限动作仍共同决定任务交接。

同时最多运行两项生成工作，每项语音准备并发为二。生成正文上限可配置为1—4000字；段队列上限 400，单任务音声缓存上限 64 MiB。网络请求有超时，语音准备另有整项期限，失败只降级受影响通道。取消后的解码、片段和回执均须匹配原授权。解码缓冲上限128 MiB、总音声时长上限10分钟，坏片段明确降级。固定音声沿用同一播放器的单片段路径。

## 服务和凭据

聊天、语音、记忆分别配置基础地址和独立凭据槽。Windows DPAPI 加密凭据，服务配置和加密凭据保存在独立数据库，不进入角色覆盖、角色导出或普通诊断。凭据槽同时包含服务类型和地址标识，改地址不会自动复用另一地址的密钥。网络请求禁止重定向，远端要求 HTTPS，本机回环地址支持 HTTP。

优先提供 Fish Audio TTS，另支持 OpenAI 兼容语音接口。音色绑定归属角色实例；导出只物化作者可分发的人格与称呼，不带本机音色绑定、服务账户或记忆身份。翻译朗读为显式选项，原文保留，片段携带与朗读文的关联。

## 本地与 Hindsight 记忆

每实例一个 SQLite 上下文数据库，所有入口要求有效的实例 UUID。保留用户原文、实际呈现的助手文字、来源和完整/部分状态；仅生成而未显示的内容不进入正常助手历史。连续排队聊天按所属轮次组织上下文，后续输入不会插入较早一轮。

上下文使用最近有限消息及最多 2400 字摘要，原始历史继续保留。摘要仅在成功并且原 epoch、水位仍一致时提交；失败不推进水位。正在呈现的部分文字不会提前被水位越过。遗忘和清空会递增本地历史代次，旧摘要或生成不能复活数据。

Hindsight 是可关闭的外部服务，允许本地部署或远端地址。bank 由本机安装身份、实例 UUID 和记忆代次生成，包、插件和界面均不能指定任意 bank。改名、模板更新和回退保持实例身份；新建伙伴拥有新命名空间。

同步默认关闭，开启后只将此后明确提交的用户消息加入持久 outbox；不自动把助手猜测、主动问候或网页材料作为用户事实。document_id 在重试中不变，服务返回成功后才移除待办。网络离线保留队列，退避重试，本地上下文仍可用。每个待办保留原服务地址，使用该地址的凭据；切换服务不重定向旧任务。

“仅清空本地历史”保留远端 bank；“遗忘本地与远端记忆”递增记忆代次、立即切换命名空间，并为曾绑定的本实例服务地址排队删除旧 bank。正在执行的旧同步先收尾，随后处理删除，避免旧写入在删除之后重建内容。服务离线时删除状态保持待办，不将本地遗忘等同于远端已删除。

## 兼容、导出与阶段边界

首次 P2 启动为已有宿主数据库创建一致性备份。实例 ID、包引用、草稿、插件覆盖和 v0.1.0 设置继续兼容。包文件保持不可变。

可按实例停用固定音声素材，后续任务生效；导出保存 enabled 标记并保留原资源字节，保护未知插件引用。人格物化保留未知身份字段，明确的人格正文取代旧 personaAsset 引用。角色导出不包含数据库、bank、密钥或运行状态。完整素材制作与引用冲突编辑器属于 P4。

P2 不提供观察、搜索、完整关怀插件、制作工作台或新渲染后端。按用户在 P2 验收中的追加要求，本阶段增加固定音声创建 Fish 私有音色、返回 ID 展示与绑定、服务连接测试和快捷试听；这只提前实现所需的音色入口，不代表整个 P3 已交付。人工验收仍需实际配置聊天与 Fish Audio 服务，验证听感、人格、Windows 环境和七项 MVP；模拟服务回归不代表真实服务兼容性通过。

## 设置页操作边界

界面将伙伴人格、共享服务、音色试听、固定素材和记忆分成独立卡片。回复语言与翻译语言由同一份 contracts/languages.json 定义，下拉选择与宿主保存校验一致；常见旧值兼容规范化，未知旧值要求重新选择。

连接测试用临时连接副本和当前填写的密钥，不改共享服务或凭据库；空白凭据只查同类同地址加密槽。聊天测试只发独立固定短提示；记忆测试只读列表；语音账户接口测试和实际合成试听分别回执。所有网络工作在宿主锁外执行，错误不显示服务原始响应体或请求凭据。

试听在网络请求前建立 preparing 音声任务，经同一调度器完整交接。用户停止、切换实例或准备超时后丢弃迟到结果；试听不写聊天历史和长期记忆，缓存只在授权的数据目录中生成并在任务收尾后回收。

创建音色只接受当前实例、当前包散列和经包校验的音频资源 ID，不接收任意文件路径。上传有数量和字节上限，文件名改为通用序号，显式请求 private。服务返回 ID 后，按发起实例和服务地址持久化创建记录；切换实例不改结果归属，不自动绑定到另一伙伴。填入 ID 与保存伙伴配置分开，状态查询必须使用创建时的服务地址。创建记录不进入模板导出。

## 完整正文与可读文本

生成正文在接收结束或断流后一次性通过 CommonMark 解析为纯文本，正文清洗、分页输入、TTS片段及实际呈现记账使用同一份文本。显示使用 textContent，不执行模型 HTML。代码内容、列表序号、段落和字面符号保留，标题、强调和围栏等格式标记不朗读。链接保留标签，不加载图片或网页。[解析器事件接口](https://docs.rs/pulldown-cmark/0.13.5/pulldown_cmark/enum.Event.html)。

历史增加显示格式标记，旧助手消息可读化只产生 displayContent，不改保存的 content；新助手消息按已经呈现的纯文本显示，避免二次解析改变代码符号。用户原文不做此变换。摘要与翻译各有独立内部长度预算，不因短句回复上限而缩短。

取消和切换仍通过实例、代次及呈现授权约束，未呈现的完整生成不写入助手历史。准备仍不占用前台锁，默认新消息保持等待当前整条回复。完整预缓冲增加首字/首声等待，换取对服务抖动的隔离；音频本身的静音或服务生成的停顿不自动裁切。
