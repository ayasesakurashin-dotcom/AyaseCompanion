# ADR 0002：P2 统一回复、服务与实例记忆

状态：已实现，待 P2 人工实机验收。应用候选版本为 0.2.0，协议沿用 1.x 的向后兼容扩展。

## 统一回复和呈现

角色实例保存角色称呼、用户称呼、人格、回复语言、音色、朗读语言及发送策略；包内人格为初始推荐值，本地修改独立保存。聊天与插件生成回复共用 CharacterReplyService 的人格组织入口，翻译和摘要使用独立内部提示词。

Rust 接受请求时固定实例、人格修订、历史代次和取消令牌。生成准备不占用呈现锁，同一实例的生成任务保留接受顺序；开始授权前再次核对人格与历史，已经开始的回复继续使用原快照。默认新消息等待当前整条回复，用户可明确改为停止当前回复。

聊天适配 OpenAI 兼容 Chat Completions SSE，只读取正文 content，忽略 reasoning 和 tool_calls，并过滤跨片段的 think 标记。正文、事件、输出和缓存均有限额；流中断保留已收到的正文，按失败收尾，不用固定后备替换已经显示的内容。无正文时，只有 generated-with-fallback 的明确后备才能接替。

文字优先策略在有效正文就绪后竞争呈现授权；语音同步策略额外等待首段音频就绪或首段语音降级。气泡在流结束、所有分页阅读完成后关闭。音频按句段并发准备、按原序号串行播放；后到首段不能被先到的后续段跳过。文字、音频和有限动作仍共同决定任务交接。

同时最多运行两项生成工作，每项语音准备并发为二。生成正文最多 4000 字；段队列上限 400，单任务音声缓存上限 64 MiB。网络请求有超时，语音准备另有整项期限，失败只降级受影响通道。取消后的解码、片段和回执均须匹配原授权。固定音声继续使用 v0.1.0 的 Web Audio 路径。

## 服务和凭据

聊天、语音、记忆分别配置基础地址和独立凭据槽。Windows DPAPI 加密凭据，服务配置和加密凭据保存在独立数据库，不进入角色覆盖、角色导出或普通诊断。凭据槽同时包含服务类型和地址标识，改地址不会自动复用另一地址的密钥。网络请求禁止重定向，远端要求 HTTPS，本机回环地址支持 HTTP。

优先提供 Fish Audio TTS，另支持 OpenAI 兼容语音接口。音色绑定归属角色实例；导出只物化作者可分发的人格与称呼，不带本机音色绑定、服务账户或记忆身份。翻译朗读为显式选项，原文保留，片段携带与朗读文的关联。

## 本地与 Hindsight 记忆

每实例一个 SQLite 上下文数据库，所有入口要求有效的实例 UUID。保留用户原文、实际呈现的助手文字、来源和完整/部分状态；仅生成而未显示的内容不进入正常助手历史。连续排队聊天按所属轮次组织上下文，后续输入不会插入较早一轮。

上下文使用最近有限消息及最多 2400 字摘要，原始历史继续保留。摘要仅在成功并且原 epoch、水位仍一致时提交；失败不推进水位。正在呈现的部分文字不会提前被水位越过。遗忘和清空会递增本地历史代次，旧摘要或生成不能复活数据。

Hindsight 是可关闭的外部服务，允许本地部署或远端地址。bank 由本机安装身份、实例 UUID 和记忆代次生成，包、插件和界面均不能指定任意 bank。改名、模板更新和回退保持实例身份；新建伙伴拥有新命名空间。

同步默认关闭，开启后只将此后明确提交的用户消息加入持久 outbox；不自动把助手猜测、主动问候或网页材料作为用户事实。document_id 在重试中不变，服务返回成功后才移除待办。网络离线保留队列，退避重试，本地上下文仍可用。每个待办保留原服务地址，使用该地址的凭据；切换服务不重定向旧任务。

“仅清空本地历史”保留远端 bank；“遗忘本地与远端记忆”递增记忆代次、立即切换命名空间，并为曾绑定的本实例服务地址排队删除旧 bank。正在执行的旧同步先收尾，随后处理删除，避免旧写入在删除之后重建内容。服务离线时删除状态保持待办，不将本地遗忘等同于远端已删除。

## 兼容、导出与阶段边界

首次 P2 启动为已有宿主数据库创建一致性备份。实例 ID、包引用、草稿、插件覆盖和 v0.1.0 设置继续兼容。包文件保持不可变。

可按实例停用固定音声素材，后续任务生效；导出保存 enabled 标记并保留原资源字节，保护未知插件引用。人格物化保留未知身份字段，明确的人格正文取代旧 personaAsset 引用。角色导出不包含数据库、bank、密钥或运行状态。完整素材制作与引用冲突编辑器属于 P4。

P2 不提供观察、搜索、完整关怀插件、音色创建、制作工作台或新渲染后端。人工验收仍需实际配置聊天与 Fish Audio 服务，验证听感、人格、Windows 环境和七项 MVP；模拟服务回归不代表真实服务兼容性通过。
