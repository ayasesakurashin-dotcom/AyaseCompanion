# P3：默认行为与有来源的 AI 能力

状态：实现中，等待人工实机验收。开发基线 v0.2.0。

默认行为仍按插件配置实例启用，未配置关闭。新增工作、随机、指针、观察、天气、日历、特殊日期和作息规则；所有回复进入既有宿主调度与统一人格，后台条件变化不取消已开始的整条回复。关怀共用主动预算，记录准入与跳过原因。

工作计时默认选择应用运行时间；另可选择设备活跃时间或手动工作计时。恢复后的时钟空隙不推断为工作。休息须满足设备空闲阈值或用户明确开始休息；动画不表示已经休息。

聊天、视觉和搜索独立配置、独立凭据槽。搜索首版支持 DeepSeek 官方 Search API，至多一次分类、一次搜索，不自动抓取网页或执行工具。关闭、禁止联网、失败和空证据有不同状态。查询使用精简公开词，不传整份历史或记忆；来源与查询时间属于本地历史，不进入朗读和长期记忆。

手动屏幕问答在发送时捕获选定外部窗口、显示器或矩形区域；准备目标不采集。句柄、进程创建时间和生命周期票据均由宿主核验，失效不能改拍其他窗口。自身窗口遮罩，原图仅在内存流转。视觉提取与角色回复分开，观察按实例、epoch、实际采集时间和范围独立保存，引用旧观察明确标记历史材料。

定时观察独立关闭；可仅保存文字观察或再请求统一角色评论。观察不写 Hindsight。全文与摘要有预算，遗忘同时失效观察和迟到结果。

天气由 Open-Meteo 按地点联网查询模型估算；可选固定地点或显式授权的 Windows 设备位置。设备位置默认关闭，系统申请仅在前台控制台显式点击后发生，后台只检查已有权限并单次读取，撤销或配置变化使在途结果失效。不使用 IP 定位，不保存精确定位或向角色提供精确坐标；查询坐标四舍五入到两位小数。定位最多5分钟、误差最多5公里；天气采样与读取最多15分钟，并校验返回地点、单位和数值，开始呈现前再次复核。页面展示设备时钟、采样/接收时间、定位时间/精度及有效状态。失败保留上一条结果供排查，但不用于关怀。

日历显式选择国家与起止年份，包含两端，单次最多20年。全部下载并校验后以一次数据库写入提交；非法区间、容量不足、来源失败、实例/历史代次变化或期间清除/替换日历均不能产生部分或迟到覆盖。单个JSON导入仍保留，来源标为用户手工核对。特殊日期按伙伴隔离，首版由用户明确编辑，不从含糊聊天自动添加。网页操作和通用设备代理不属于本轮默认启用能力。


新增数据为独立附加表/文件；升级前保留 SQLite 一致性备份。角色导出包含适用插件配置，但不包含观察、特殊日期私人档案、服务设置、凭据和运行统计。旧工程只读参考，不共享其数据库、身份或密钥。

参考实现：TrayBuddy 的屏幕票据、搜索路由、观察分表、关怀预算及音色管理。优先遵守本工程非抢占与实例隔离原则。

接口核对：2026-10-29，[DeepSeek Search](https://api-docs.deepseek.com/api/search/)、[Open-Meteo](https://open-meteo.com/en/docs)、[香港天文台公农历对照](https://www.hko.gov.hk/en/gts/time/conversion.htm)。接口核对不代表真实账号验收通过。

位置接口核对：2026-10-30，[Microsoft Geolocator](https://learn.microsoft.com/en-us/uwp/api/windows.devices.geolocation.geolocator.getgeopositionasync)、[Windows 位置隐私](https://support.microsoft.com/en-us/windows/privacy/windows-location-service-and-privacy)。真实设备权限、精度和定位成功率由人工验收。


P3复验修订（2026-10-31）：工作相关数值支持至少12小时；模型按每个实际帧缓存alpha外接范围，由宿主Windows鼠标穿透控制排除透明排版空间，气泡布局与交互命中分离。命中上报绑定当前伙伴/包且有短有效期；不把已开始呈现的内容改成可抢占。

聊天和独立视觉分别配置思考接口/强度，默认关闭；未知型号不猜扩展参数，固定思考型号不能伪装成关闭。翻译复用聊天模型，使用当前人格/称呼且独立请求关闭思考；在分段前及译后仅去除明确舞台注释，保留普通括号信息。字数预算在完整候选上按句收尾，无句界则明确省略；原先的逐字符硬截断不再直接作为最终正文。诊断记录结束原因与裁剪元数据，文字和TTS使用同一最终正文。
