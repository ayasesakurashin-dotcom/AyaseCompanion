# P3：默认行为与有来源的 AI 能力

状态：实现中，等待人工实机验收。开发基线 v0.2.0。

默认行为仍按插件配置实例启用，未配置关闭。新增工作、随机、指针、观察、天气、日历、特殊日期和作息规则；所有回复进入既有宿主调度与统一人格，后台条件变化不取消已开始的整条回复。关怀共用主动预算，记录准入与跳过原因。

工作计时默认选择应用运行时间；另可选择设备活跃时间或手动工作计时。恢复后的时钟空隙不推断为工作。休息须满足设备空闲阈值或用户明确开始休息；动画不表示已经休息。

聊天、视觉和搜索独立配置、独立凭据槽。搜索首版支持 DeepSeek 官方 Search API，至多一次分类、一次搜索，不自动抓取网页或执行工具。关闭、禁止联网、失败和空证据有不同状态。查询使用精简公开词，不传整份历史或记忆；来源与查询时间属于本地历史，不进入朗读和长期记忆。

手动屏幕问答在发送时捕获选定外部窗口、显示器或矩形区域；准备目标不采集。句柄、进程创建时间和生命周期票据均由宿主核验，失效不能改拍其他窗口。自身窗口遮罩，原图仅在内存流转。视觉提取与角色回复分开，观察按实例、epoch、实际采集时间和范围独立保存，引用旧观察明确标记历史材料。

定时观察独立关闭；可仅保存文字观察或再请求统一角色评论。观察不写 Hindsight。全文与摘要有预算，遗忘同时失效观察和迟到结果。

天气采用用户选定固定地点，由 Open-Meteo 提供数值预报，明确标记模型估算、地点、采样时间与来源，不宣称实测或自动定位。日历显式导入官方公农历资料或国家假日日历后本地使用；特殊日期按伙伴隔离，首版由用户明确编辑，不从含糊聊天自动添加。位置自动探测、IP 定位、网页操作和通用设备代理不属于本轮默认启用能力。

新增数据为独立附加表/文件；升级前保留 SQLite 一致性备份。角色导出包含适用插件配置，但不包含观察、特殊日期私人档案、服务设置、凭据和运行统计。旧工程只读参考，不共享其数据库、身份或密钥。

参考实现：TrayBuddy 的屏幕票据、搜索路由、观察分表、关怀预算及音色管理。优先遵守本工程非抢占与实例隔离原则。

接口核对：2026-10-29，[DeepSeek Search](https://api-docs.deepseek.com/api/search/)、[Open-Meteo](https://open-meteo.com/en/docs)、[香港天文台公农历对照](https://www.hko.gov.hk/en/gts/time/conversion.htm)。接口核对不代表真实账号验收通过。
