# 角色前景与背景装饰扩展计划书

状态：A 至 F 已完成，独立装饰扩展已通过人工实机验收，正式版本与后续开发基线为 v0.4.1。P5 尚未启动。

本轮为现有序列帧架构增加通用装饰层，使角色作者能够在主体前方、后方布置零个或多个静态或动画装饰。装饰各自控制素材、播放速度、锚点、位置、大小、开关和适用状态，并在工作台、制作预览与实际桌面保持一致。

本计划已按 A 至 F 完成实施、实机验收与固版。此项作为独立架构扩展，不启动 P5，不修改此前正式版本、旧 TrayBuddy 程序或旧应用独立输入窗口的行为。

## 1. 范围与实现原则

| 需求 | 本轮方案 |
| --- | --- |
| 静态素材与动画片段 | 支持包内 PNG/WebP 静态图，以及单图、网格、显式帧矩形片段；动画沿用既有帧序和时长能力 |
| 独立播放 | 每层有独立播放进度与速度，不切换主体动作，不占用回复任务 |
| 前景和背景 | 背景始终在主体后方，前景始终在主体前方；各组内支持多个装饰排序 |
| 整体窗口关系 | 所有装饰与主体属于同一原生桌宠窗口、同一合成画布，共用窗口移动、置顶、隐藏和显示 |
| 独立空间配置 | 每层可配置模型相对锚点、自身对齐点、偏移、目标大小及缩放 |
| 状态控制 | 全状态通用，或选择 idle、music、quiet；不同状态可使用不同装饰组合 |
| 数量 | 允许零个或多个，不新增固定层数上限，不截取前若干层执行 |
| 制作流程 | 素材库、装饰编辑、整体验证、制作预览、导入导出同步支持 |

本轮不增加逐帧身体部位绑定、骨骼、物理、跟随手腕的饰品、任意脚本效果，也不增加插件临时触发装饰的命令。花环、底座、背后光环及持续循环光效均在本轮范围内。装饰层配置可为以后扩展保留稳定 ID，但未实现的能力不显示为可用。

## 2. 整体合成与前后顺序

所有画面在桌宠已有的原生窗口内完成合成，不为任何装饰建立独立桌面窗口。默认采用一张 Canvas，按以下顺序绘制：

1. 背景组：从最下层绘制到最上层。
2. 主体角色：当前基础循环、互动动作或基础过渡。
3. 前景组：从最下层绘制到最上层。

气泡和操作按钮继续作为同一桌宠窗口内的界面内容，位于角色合成画面上方。独立聊天输入窗口保持原有职责，本轮不处理其与其他应用的层级问题。

前景/背景分组是硬边界；组内“置顶”不能越过主体。若作者希望把某装饰从背后移到前方，必须明确更改所属组。支持上移、下移、置顶和置底，保存、重启、导出再导入后顺序保持一致。底层排序采用组别、顺序值和稳定的同序判定，不能因资源异步加载先后改变遮挡关系。

切换其他普通应用时，操作系统面对的是整个桌宠窗口，不存在角色置顶而某个装饰窗口被压在新应用下方的独立窗口关系。全屏、隐藏等策略也作用于整体；这不改变操作系统对独占全屏或系统安全桌面的既有处理。

## 3. 装饰配置与定位

每个装饰有独立稳定 ID。相同素材或同一动画片段可被多个装饰引用，各装饰拥有自己的位置、层级和播放进度；图像解码结果可以共享。

| 配置项 | 含义与建议默认值 |
| --- | --- |
| 名称与 ID | 名称用于编辑器识别；ID 用于保存、引用、更新和诊断 |
| 启用 | 默认启用；关闭保留完整配置 |
| 所属组 | 前景或背景，新建时由作者选择 |
| 组内顺序 | 较大的顺序值更靠前，仅在所属组内比较 |
| 内容来源 | 静态图片素材，或动画片段；两种来源明确互斥 |
| 相对锚点 | 相对于主体固定逻辑画布的 x/y 比例坐标；可选中心、底部中心、既有 feet 锚点，或自定义 |
| 自身对齐点 | 装饰自身固定参考框的 x/y 比例坐标，用于决定中心、底部等哪个位置对准模型锚点 |
| 横纵偏移 | 模型逻辑像素；向右、向下为正，随桌宠整体缩放和 DPI 一起转换 |
| 大小 | 默认使用原图或片段固定参考尺寸；可指定目标宽/高，默认锁定宽高比 |
| 独立缩放 | 默认 100%，在目标大小基础上调整，只影响本装饰 |
| 播放速度 | 默认 1 倍，必须是有限正数；使用共享渲染时钟计算，不修改主体片段的时长 |
| 适用状态 | 默认全状态通用；可多选 idle、music、quiet；一个也不选表示不在任何状态显示 |

位置和大小使用模型逻辑坐标，不把高 DPI 的物理屏幕像素直接写入角色包。工作台标明单位，并在预览中显示当前缩放后的效果。相对锚点固定在主体逻辑画布上，不随招手、眨眼等每帧透明轮廓变化，防止装饰漂移。

引用动画片段时复用帧区域、顺序和时长，位置由装饰自身配置决定，不叠加主体片段的脚底定位和偏移。一个片段被主体和装饰同时使用时，双方进度互不干扰。对于帧矩形尺寸不同的片段，使用固定参考框和固定缩放，不对每一帧重新适配尺寸。

选择一张序列帧图集作为“静态图片”只会显示整张图，工作台应说明区别，并提供创建/选择动画片段的入口。Ema 花环作为本机验证样例：8 列、5 行、每格 199×71、40 帧、200 毫秒/帧、正向循环；源图不需要修改。

## 4. 状态与播放生命周期

显示条件为“启用，并且当前基础状态在适用范围内”。全状态通用不排斥状态专用装饰，两者可以同时存在；多层组合不沿用回复变体的“专用优先替换通用”规则。希望替换时，作者为不同层设置互斥状态即可。

采用以下已确认的默认行为：

- 依据宿主已经应用的基础状态判定，不根据尚在等待的目标状态提前切换。临时招手等互动动作不产生第四种装饰状态。
- 基础状态过渡期间保留原状态的装饰，在宿主提交目标状态时统一切换。已有回复文字、声音和主体动作不因装饰切换而取消。
- 动画装饰显示期间独立循环；新回复、翻页、动作结束、同状态快照更新不重置装饰进度。
- 因状态不匹配或关闭而隐藏时暂停该层；重新显示从暂停位置续播。应用重启、切换角色、加载另一个项目或明确重新开始预览时从头播放，不保存跨启动的逐帧进度。
- 修改位置、大小或排序不重置进度；修改播放速度保持当前相位连续；替换素材或改变片段帧定义时重置对应层。
- 点击桌宠“停止当前回复”仍只停止当前回复；常驻装饰继续运行。工作台“停止制作预览”释放该次预览的全部角色与装饰播放器。

装饰不产生文字/声音输出，不向现有有限动画通道发送完成回执，不持有任务播放锁。若将来增加“随任务出现、播放一次”的效果，应另行定义生命周期，本轮不借常驻循环隐式实现。

## 5. 显示范围、交互与屏幕边界

渲染系统区分三种范围：主体参考范围用于气泡定位；整体绘制范围用于容纳角色和装饰；主体交互范围用于点击和拖动。装饰不能把三者合并成一个大的鼠标拦截矩形。

角色和装饰共用同一坐标变换、整体位置、缩放及窗口边界计算。增加画布留白或装饰超出原模型画布时，保持主体锚点的屏幕位置稳定，不把主体重新居中导致位置跳变，也不因装饰较大而自动缩小主体。

配置加载时计算主体及已启用装饰的稳定绘制范围，包含装饰可能在各状态显示的范围与片段各帧范围。切换状态无需每帧重新改变窗口大小。修改启用、位置、大小或配置时重新计算；资源全部就绪后提交新的合成场景，避免分层闪现。

当整体能放入当前屏幕工作区时，按整体范围调整位置。若作者配置的整体尺寸超过工作区，编辑器给出明确提示；运行时保持各部分的相对位置和比例，优先使主体可见，屏幕外部分裁切，不分别移动或缩小某个装饰。不同 DPI 的显示器之间统一换算。

装饰默认不接收鼠标，不参与角色点击判定、拖动区域或工具按钮显现判定。可见花环落在主体范围外时，其下方其他应用仍能收到鼠标操作；落在主体范围内时，角色原有交互继续有效。气泡定位仍取稳定主体参考范围，操作按钮保持可用且不会被装饰遮住。

## 6. 工作台与日常配置

角色制作项目新增“前景与背景”页面，背景、前景分别为可折叠列表。列表明确标注靠前/靠后方向，每项显示缩略图、名称、开关、适用状态和顺序操作。允许空列表；添加、复制、删除与排序不设固定条目上限。

选中装饰后，在预览旁编辑素材、锚点、自身对齐点、偏移、大小、缩放、速度和状态。提供相对锚点标记及整体范围辅助线，辅助线只用于编辑器。沿用现有逐项折叠和素材分类，不要求作者直接编辑 JSON。

制作预览共享正式运行的解析、合成、时钟和状态判定。支持查看静态整体、播放主体片段、模拟 idle/music/quiet 及模拟互动；每种方式都显示适用的装饰。位置、大小、顺序和速度调整可刷新预览，保存后使用同一有效配置进行完整插件模拟。参数预览不调用 AI 服务，也不修改日常伙伴状态。

素材引用追踪增加装饰引用：重命名同步更新；删除仍被装饰引用的素材或片段时明确列出引用并阻止误删；替换图集后重新校验帧范围。片段选择器区分“作为主体动作预览”和“作为装饰引用”，不能自动把花环加入主体语义映射。

日常伙伴提供按层开关及恢复包内推荐值，开关作为当前伙伴本地覆盖保存。完整的锚点、排序和动画制作放在工作台。导出当前有效角色包时包含用户选择的有效装饰开关，原始角色包保持可追溯。

## 7. 协议、兼容与资源管理

在 sprite 描述中增加可选的 `decorations` 列表，并以 `decorationVersion: "1.0"` 标明装饰子协议版本。字段覆盖稳定 ID、前/背景、顺序、来源、定位、大小、速度、启用与状态集合。列表不设固定 `maxItems`；顺序值重复时也有确定的回退顺序，重复 ID 则报错。

原有 `clips` 保留为可复用片段库。装饰持有独立播放实例，不把自身放入 `baseModes`、`semanticCues` 或回复任务列表。Rust 负责配置与资源校验，前端只执行已解析的场景；工作台与正式宿主共用同一实现。

兼容原则：

- 没有装饰字段的旧角色包、旧项目继续原样显示，不要求迁移已有作品。
- 新项目保存与包导入导出保留装饰 ID、顺序、开关、状态和完整资源引用，往返后结果一致。
- 角色包升级保留对应层的本地开关覆盖；删除及恢复遵守已有稳定 ID、显式覆盖和回滚规则，不复活用户关闭的同一层。
- 新装饰包在旧 v0.4.0 上的降级边界须验证并在导出说明中标明：旧版不支持装饰，不能声称外观完整。若旧版导入流程无法可靠保留新字段，则明确最低应用版本，不把旧版再次导出当作完整编辑路径。
- 关闭或未启用的装饰仍保留配置。可选装饰素材缺失时跳过该层并提供可定位提示，主体仍可运行；已声明完整性却散列不符的包继续按完整性错误处理。

不新增“最多几个背景/前景”的限制。现有包大小、文件大小、图像解码预算、帧布局及数值合法性校验仍适用；不能用取消数量限制绕过这些约束。较多层共享图像缓存和一个渲染调度，不为每层创建独立窗口或定时器，不静默丢弃后面的层。编辑器可显示实际资源用量与性能提示，不承诺任意数量都保持相同帧率。

切换角色、停止制作预览、关闭窗口和替换项目时释放全部装饰资源。异步图像加载结果受实例、项目修订及加载代次约束，旧结果不能补画到新角色。单层加载失败不破坏其他已验证资源和主角色运行。

## 8. 实施步骤与交付物

| 步骤 | 工作 | 完成依据 |
| --- | --- | --- |
| A 协议与场景解析 | 冻结字段、默认值、排序、状态和旧包兼容；补充共享校验及通用测试样例 | 旧包无需改动；合法/非法配置结果一致 |
| B 合成播放 | 同窗口合成、固定前后分组、独立进度、资源复用与释放 | 主体、装饰相互独立且排序稳定 |
| C 桌面范围 | 整体窗口边界、固定主体锚点、DPI、点击穿透与气泡定位 | 扩大显示范围不扩大无关交互范围 |
| D 工作台与导出 | 编辑列表、素材引用、预览、伙伴开关、项目和包往返 | 制作预览与导入后实机一致 |
| E 候选交付 | 回归检查、本机 Ema 示例、制作操作文档、专项验收表 | 用户可从素材导入完成制作并逐项复验 |
| F 验收后固版 | 用户明确通过后才归档、固定新基线并按授权发布 | 保留 v0.4.0 标签及附件，新增版本可回滚 |

本轮候选与正式版本号在交付时依据既有版本策略单独确定，不借版本号表示 P5 已完成。本次计划确认不等于实机验收通过，也不授权提前发布未验收代码。

候选交付包含独立程序、功能说明、完整专项验收清单，以及基于本机 Ema 素材的花环制作教程与整理后的素材。用于证明背景和多层排序的通用图形样例可以公开；Ema 原始图像、实际测试结果、截图和诊断只留本机。

实施后为每项补充具体操作、候选版本和空白结果栏；下表为本轮必须覆盖的范围，不是已通过记录。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| D01 | 导入没有装饰的旧角色包/项目 | 外观、动作、气泡、点击与已有版本一致 |
| D02 | 单个静态前景和单个静态背景分别制作 | 图片位置、大小和组别正确，零装饰同样可运行 |
| D03 | Ema 花环与角色同时循环 | 40 帧、200 毫秒/帧的默认节奏正确，角色不被花环替换 |
| D04 | 同时布置多个相互重叠的前景和背景 | 背景始终在主体后，前景始终在主体前 |
| D05 | 各组上移、下移、置顶、置底并重启 | 遮挡关系与保存顺序一致，操作不越组 |
| D06 | 添加较多装饰并复用同一素材 | 无固定层数门槛，不遗漏尾部条目；分别计时、共享资源；记录实际资源用量 |
| D07 | 修改独立速度并播放招手、音声和长文字 | 装饰速度独立；回复不重置装饰，任务正常完成交接 |
| D08 | 调整模型相对锚点、自身对齐点、偏移和大小 | 定位可预测，主体做动作时装饰不随透明轮廓抖动 |
| D09 | 拖动、缩放及在不同 DPI 显示器间移动 | 所有组成部分保持相对位置、比例与顺序 |
| D10 | 打开/切换/最大化其他普通应用、显示隐藏桌宠 | 整体显示隐藏或被覆盖，不出现角色与装饰分属不同窗口层级 |
| D11 | 分别配置 idle、music、quiet、全状态和空状态 | 各状态显示正确组合；全状态层与专用层同时显示；空状态层不显示 |
| D12 | 在回复和基础过渡期间改变媒体/全屏事实 | 按已应用状态切换；不提前使用等待中的目标，不中断回复 |
| D13 | 隐藏后恢复、同状态更新、单独开关某层 | 按约定暂停续播；其他层与主体不重新开始 |
| D14 | 点击停止当前回复，再停止制作预览 | 前者不停止常驻装饰；后者释放全部预览播放器 |
| D15 | 装饰超出原模型画布，点击装饰外扩部分与透明部分 | 画面可显示；下方应用可交互；主体点击、拖动、按钮正常 |
| D16 | 花环、长气泡、按钮同时出现 | 装饰不改变气泡主体参照，不遮挡操作控件，阅读与分页正常 |
| D17 | 贴近屏幕边缘及超过屏幕的装饰配置 | 可容纳时整体约束；超大时提示并按约定裁切，各部分不分别移位 |
| D18 | 工作台修改、保存、预览主体片段和模拟插件 | 预览与同配置的实际桌面一致，无主体/装饰片段混淆 |
| D19 | 重命名、替换和删除被引用素材/片段 | 引用同步更新；不允许误删；帧布局错误明确报告 |
| D20 | 项目另存、角色包导出导入、再导出 | 素材、层级、顺序、状态和定位完整往返 |
| D21 | 伙伴开关、恢复推荐值、包升级和回退 | 本地覆盖隔离且可追溯，其他伙伴不受影响 |
| D22 | 缺失可选装饰、坏图集、重复 ID、非法速度 | 错误定位明确；按类型拒绝或降级，不使有限任务永久等待 |
| D23 | 快速切换角色/项目与反复开始停止预览 | 无旧装饰闪回、旧加载回调越界或持续资源累积 |
| D24 | 新包在 v0.4.0 上进行兼容检查 | 实测确定降级/最低版本边界，不误报完整外观兼容 |

自动验证覆盖排序、状态匹配、时间计算、坐标变换、无层数截断、包与项目往返、资源失败及旧回调隔离。按仓库约定完成构建与必要回归检查；实际遮挡、点击穿透、DPI、多屏和视觉节奏由用户实机验收，自动检查不代替体验结论。

## 10. 确认后的执行边界

用户确认本计划后实施 A 至 E，交付候选和可填写的专项验收清单。实机验收通过后再处理 F。P5、旧 TrayBuddy 修复、身体部位绑定和插件临时特效触发仍需另行授权。

本计划中的默认值，尤其是“同窗口合成”“状态依据已应用基础状态”“隐藏暂停、显示续播”“装饰不扩大点击区域”，在确认后作为本轮实现和验收依据。
