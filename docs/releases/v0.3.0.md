# v0.3.0 · P3 基线

P3 已完成人工实机验收，v0.3.0 固定为后续开发基线。本版本继承 v0.2.0 的人格、聊天、语音与记忆，以及 v0.1.0 的角色包、独立实例和完整任务调度。此前版本的源码标签和发布附件继续保留。

## 新增功能

- 工作/休息、随机、点击、定时/周期、观察、天气、日历、特殊日期及作息行为。按伙伴和配置启停，主动互动共用预算，不抢占已开始的完整回复。
- 显式授权的屏幕问答与定时观察；只保留文字证据，原图不落盘。观察原文、有界摘要、来源时间及引用按伙伴隔离，遗忘与清空会使迟到结果失效。
- 独立视觉服务，以及 DeepSeek 公开资料搜索。搜索返回来源证据，不自动抓取网页或执行设备操作。
- 固定地点或可选的 Windows 设备位置查询天气，校验位置质量、地点、时间与单位；页面展示当前时间、最近结果及有效状态。位置读取默认关闭。
- 包含起止年份两端的日历批量导入和伙伴独立特殊日期；显式导入后可离线使用，来源失败不产生部分覆盖。
- 聊天/视觉的模型思考协议与强度设置，默认关闭；翻译参考伙伴人格并独立请求关闭思考。语音稿过滤明确舞台注释，保留普通括号说明；有界回复优先按完整句末收尾。
- fixed/fallback 的多段文字、音声和动作素材，按各自顺序播放并共同持有一个任务；随机变体避免连续重复，每页遵守全局最少阅读时间。
- idle、music、quiet 与通用状态回复。专用优先，无匹配不回应；开始前复核状态，已开始任务完整收尾。支持直接选择模型动画片段及连续片段。
- 按当前动画帧更新交互范围，透明排版空白及气泡区域可穿透；模型拖动和工具按钮保留。

## 使用与升级

下载 Windows x64 便携 ZIP，完整解压后运行 `AyaseCompanion.exe`，需要 Microsoft Edge WebView2 Runtime。首次使用导入自己的角色包并创建伙伴；升级前先从托盘退出旧程序，已有实例、人格、音色和服务配置继续使用。

新服务和行为需要单独配置及启用，未配置不会自动采集屏幕或读取位置。聊天、Fish Audio 和本地/远端 Hindsight 配置见 [P2 服务指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.3.0/docs/p2-user-guide.md)，新增功能及状态、多素材配置见 [P3 指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.3.0/docs/p3-user-guide.md)。密钥只在程序设置中填写。

首次从旧版升级到 P3 时保留一致性数据库备份。回滚程序与回滚用户数据是两件事：退出程序并保留现有数据副本，再按指南恢复对应备份与程序版本，不删除现有伙伴身份和角色包。

## 边界与版本保留

- 当前为单伙伴、Windows 序列帧宿主。制作工作台、完整安装/更新流程、新渲染后端及通用设备代理属于后续阶段。
- 中国日历来源为公农历、传统日期及节气，不推断调休；工作日须导入已核对日期表。其他国家仅按明确适用的公共假日处理。
- 天气是联网模型估算，须满足时效与位置质量要求；无法取得有效设备位置时不会改用 IP 推测。没有支持媒体会话的播放器不会被当作可靠媒体来源。
- 模型与音色能力、账号权限、额度及网络由服务提供者决定。位置、屏幕和联网能力遵循用户开关与系统权限。
- 正式构建仅移除候选标识，业务逻辑沿用已验收实现。公开附件仅含程序、通用指南、构建标识和校验值，不附带 Ema 图像/音声、用户配置、凭据、实际验收记录、诊断或截图。

`SHA256SUMS.txt` 校验本版本便携 ZIP，包内另附逐文件校验值。v0.1.0 与 v0.2.0 的标签、Release 和附件保持不变；后续阶段从 v0.3.0 继续，不覆盖已发布版本。
