# v0.1.0 · P0/P1 基线

P0/P1 已完成人工实机验收。该版本固定为后续开发基线。

## 功能范围

- 角色包校验、导入、实例管理、配置编辑、导出、更新和回退。
- Rust 权威调度：文字、固定音声与动作完整交接，支持优先级、队列、取消和迟到回执隔离。
- Windows 透明桌宠、序列帧播放、拖动缩放、独立输入窗口、托盘与控制台。
- 随模型比例变化的分页气泡，打字机显示、阅读停留与自动收起。
- 启动问候、全屏安静、媒体姿态与完整姿态退出；自身音声通过 Web Audio 播放。
- 声明式规则插件、夜间提醒样例、配置表单与本机诊断。

## 使用与边界

Windows x64 便携程序，需要 Microsoft Edge WebView2 Runtime。角色包独立导入，发布包不含 Ema 素材、用户数据或测试记录。AI、TTS、记忆、制作工作台及安装升级属于后续阶段。

全屏检测仅针对桌宠所在显示器的前台无标题栏窗口；媒体检测依赖播放器公开的 Windows GSMTC 会话。详细边界见 [ADR](../adr/0001-p0-p1-runtime.md)。

版本标签固定为 `v0.1.0`。后续版本保留公开提交链和旧 Release；应用文件回滚与用户数据回滚分别处理。
