# v0.4.0 · P4 基线

P4 已完成人工实机验收，v0.4.0 固定为后续开发基线。本版本继承 v0.3.0 的默认行为、AI 服务与状态回复，以及既有角色隔离和完整任务调度。此前版本的源码标签和发布附件继续保留。

## 新增功能

- 独立制作工作台：新建角色、每日提醒规则插件和气泡主题，也可从现有包或当前伙伴制作副本。草稿、素材及项目修订与日常伙伴数据分离，可保存、另存和重新打开。
- 分类素材库：图片与图集缩略图、音声和固定文字，支持折叠、查找、替换、引用检查、安全重命名和删除。模型与插件参数支持逐项、逐层折叠。
- 单图、网格和逐帧矩形模型，动作方向、帧时间、锚点、基础状态与语义映射。片段选择、预览和停止集中在画面旁。
- 公共参数表单、状态专用和通用回复、多段文字、顺序音声与动画，以及独立规则插件的制作、导入和角色配置。
- 虚拟时间、点击、媒体、全屏、天气、日历、累计时长及 idle/music/quiet 模拟。复用正式调度、资源解析与呈现组件，正确按模拟状态匹配回复。
- 默认无联网调用的模拟预览；真实聊天与合成语音分别显式开启，使用项目人格和所选音色，不访问伙伴历史、记忆、屏幕或搜索。
- 纯色或 PNG/WebP 九宫格主题，颜色、字体、边距、尾巴、阅读时间与显现速度。独立主题包和角色推荐主题均由用户明确选择采用。
- 气泡左右/上下像素偏移、可选最大宽高；短回复按内容收缩，手动高度可超过模型但受屏幕范围限制。输入窗口背景不透明度独立调整，文字与按钮保持清晰。
- 共享校验的角色、插件及主题包导出；未知字段和未知插件保留。更新预览比较旧推荐、新推荐与用户配置，保留用户修改和删除，冲突可逐项选择；回退恢复对应包和配置，伙伴身份保留。

## 使用与升级

下载 Windows x64 便携 ZIP，完整解压后运行 `AyaseCompanion.exe`，需要 Microsoft Edge WebView2 Runtime。升级前先从托盘退出旧程序，已有伙伴、人格、音色和服务配置继续使用。首次从旧版打开已有档案时保留升级前宿主档案备份。

从素材创建角色、制作插件、导入背景图片、主题选择、模拟预览和更新回退见[制作工作台指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.0/docs/07-studio-guide.md)。聊天、Fish Audio 与本地/远端 Hindsight 配置见[服务指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.0/docs/p2-user-guide.md)，观察、天气、日历和行为开关见[P3 指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.0/docs/p3-user-guide.md)。密钥只在程序设置中填写。

制作项目与分发包用途不同：项目用于继续编辑，分发包用于导入、运行和更新。全局主题独立保存，导入或切换角色不会自动覆盖它。真实服务预览可能计费，固定素材预览在本机播放。

## 边界与版本保留

- 当前为单伙伴、Windows 序列帧宿主。P5 的完整安装、升级、长期可靠性与性能验收，以及后续渲染后端和隔离代码插件仍属后续阶段。
- 规则插件采用数据协议，不执行任意脚本、命令或设备操作。主题也仅使用受校验的数据与包内图片。
- 程序版本、角色包版本、制作项目与用户数据分别保存；回滚程序不等于恢复数据。退出应用并保留当前数据副本后，再恢复相应程序和数据备份，不删除伙伴身份。
- 正式构建仅更新候选/已验收标识，业务逻辑沿用已验收实现。公开附件仅含程序、通用指南、构建标识与校验值，不附带 Ema 图像/音声、个人配置、凭据、实际验收记录、诊断或截图。

`SHA256SUMS.txt` 校验本版本便携 ZIP，包内另附逐文件校验值。v0.1.0、v0.2.0、v0.3.0 的标签、Release 和附件保持不变；后续阶段从 v0.4.0 继续，不覆盖已发布版本。
