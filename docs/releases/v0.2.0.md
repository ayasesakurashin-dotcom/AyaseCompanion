# v0.2.0 · P2 基线

P2 已完成人工实机验收，v0.2.0 固定为后续开发基线。本版本继承 v0.1.0 的角色实例、固定播放、任务调度与基础姿态恢复。

## 功能范围

- 每个伙伴独立的人格、称呼、语言、音色绑定、草稿、聊天原文与有界摘要；同源角色包的实例彼此隔离。
- OpenAI 兼容聊天、Fish Audio 合成语音和可选的 OpenAI 兼容语音接口；各服务单独配置和关闭，凭据按服务类型与地址由 Windows 加密保存。
- 服务连接测试、快捷试听、从当前伙伴的固定音声创建 Fish 私有音色，返回 ID 展示、复制、绑定与状态查询。
- 固定、生成和明确后备回复；聊天、生成问候及生成提醒共用伙伴人格。
- 完整正文生成后由本地动画呈现和分页，Markdown 转为适合气泡的可读文本；支持1—4000字上限和可调阅读时间。
- 可选文字优先或音声就绪后开始；音声预缓冲、预解码后顺序播放，文字、音声和动作完整收尾后交接。
- 独立本地上下文、实际呈现记账、摘要与历史代次；可配置本地或远端 Hindsight，按实例隔离 bank，明确用户输入选择性同步，离线重试与受限遗忘。
- 伙伴独立停用固定音声、人格和插件覆盖编辑、角色包导出往返，保留未知字段、插件条目和原素材。

## 使用

下载 Windows x64 便携 ZIP，解压后运行 `AyaseCompanion.exe`。需要 Microsoft Edge WebView2 Runtime，角色包另行导入。升级前请先从托盘退出旧程序。

已有伙伴和设置继续使用；首次 P2 升级为旧宿主数据库建立备份。程序文件、角色包和用户数据分别保留，回退程序不能代替数据恢复。

服务配置、音色创建、两种呈现策略和本地/远端 Hindsight 接入方法见[配置说明](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.2.0/docs/p2-user-guide.md)。密钥只在程序设置中填写。

## 边界与版本保留

- 当前同时运行一个伙伴。完整预缓冲增加首字和首声等待，气泡显现速度与网络收包分离；合成音频本身的停顿不自动裁切。
- 真实服务的模型、音色权限、额度及网络由相应提供者决定。音色创建只在用户点击上传后发送所选素材；试用合成同样可能使用服务额度。
- Hindsight 可关闭；远端离线时保留本地上下文和同步待办。遗忘只管理本实例创建的命名空间，不提供任意 bank 操作。
- P3 其余功能、完整制作工作台和后续渲染后端尚未交付。
- 公开附件仅包含程序、通用说明和散列，不附带 Ema 图像或音声、账户配置、用户数据、验收批注、诊断、截图或具体测试记录。

`SHA256SUMS.txt` 校验便携 ZIP，包内另附各文件校验值。v0.1.0 的标签和附件继续保留，后续版本使用新的不可变标签与独立附件。
