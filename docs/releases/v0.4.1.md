# v0.4.1 · 角色装饰与制作流程扩展

角色装饰扩展及制作流程优化已完成人工实机验收，v0.4.1 固定为后续开发基线。本版本继承 v0.4.0 的制作工作台、角色隔离、AI 服务与完整任务调度。P5 尚未启动。

## 新增功能

- 角色前景与背景：可放置零个或多个静态图片或循环动画，分别调整组内顺序。背景始终在主体后、前景始终在主体前，全部在同一窗口和画布合成，随角色一起移动、缩放和显示。
- 独立装饰参数：每层拥有自己的素材、播放速度、相对锚点、偏移、大小、缩放与开关，可按 idle、music、quiet 或全状态显示。装饰不占回复任务，不扩大鼠标交互范围，气泡仍以角色主体定位。
- 连续播放与柔和切换：普通回复不重置装饰进度；隐藏立即暂停，再显示时续播。状态或开关变化约用 200 毫秒淡入淡出，快速反向切换从当前透明度继续。初始加载直接显示当前组合，停止预览和切换项目清理旧画面。
- 伙伴独立开关：日常使用时可启用、关闭装饰或恢复推荐值；配置按伙伴保存，并参与角色包更新、回退和有效配置导出。
- 直接创建动作片段：“动作与映射”新增创建窗口，支持静态图片、规则网格与逐帧矩形动画，提供帧时间、方向和可选往返设置。创建后可用于主体预览、回复动作或装饰来源。
- 切片推算与检查：读取真实图片尺寸，根据作者填写的行列或单帧尺寸推算其余参数，显示切片边界与播放帧序。创建时使用宿主的资源校验，拒绝越界、超容量和非法数值；留白、重复矩形等合法布局由作者通过预览确认。
- 各页整体预览：角色、插件和主题项目的每个制作页面均提供“保存并开始整体预览”。先保存编辑再显示场景，不依赖模拟日期或插件触发条件；文字、音声和插件回复仍可单独模拟。重启预览后的会话隔离阻止旧回执和旧生成结果影响新场景。

## 使用与升级

下载 Windows x64 便携 ZIP，完整解压后运行 `AyaseCompanion.exe`，需要 Microsoft Edge WebView2 Runtime。升级前从托盘退出旧程序，保存制作项目并保留用户数据备份。已有伙伴、人格、音色和服务配置继续使用，旧角色包无需添加装饰即可正常运行。

制作入口和项目保存见[制作工作台指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.1/docs/07-studio-guide.md)，前后景参数、排序与状态规则见[装饰制作说明](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.1/docs/09-decoration-authoring-guide.md)，静态及序列帧创建见[动作片段指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.1/docs/11-clip-creation-guide.md)。

整体预览显示主体与装饰，查看气泡和回复时使用对应的文字或插件预览按钮。真实聊天与语音预览仍须显式开启，可能计费；密钥只在程序设置中填写。服务配置见[聊天、语音与记忆指南](https://github.com/ayasesakurashin-dotcom/AyaseCompanion/blob/v0.4.1/docs/p2-user-guide.md)。

## 边界与版本保留

- 装饰跟随角色整体的固定逻辑画布，不提供随手腕等身体部位逐帧移动的绑定，也不包含插件临时特效触发接口。装饰数量没有固定上限，实际容量仍受图片资源预算和设备性能约束。
- 参数推算不能仅凭图片尺寸确定美术分帧方案，也不能保证动作连贯或节奏正确；最终切片与播放效果由作者预览确认。
- 显示和编辑装饰需要 v0.4.1 或更新版本。v0.4.0 可保留装饰定义，但不绘制或编辑这些层；回退前应保存新角色包、制作项目和当前用户数据。
- 当前仍为单伙伴、Windows 序列帧宿主。P5 的长期可靠性、性能及完整安装升级工作，以及后续渲染后端和隔离代码插件属于后续阶段。
- 公开附件仅含程序、通用指南、构建标识与校验值，不附带 Ema 图像或音声、个人配置、凭据、实机记录、诊断或截图。

`SHA256SUMS.txt` 用于校验便携 ZIP，包内另附逐文件校验值。v0.1.0 至 v0.4.0 的标签、Release 和附件继续保留；后续开发从 v0.4.1 继续，不覆盖既有发布版本。
