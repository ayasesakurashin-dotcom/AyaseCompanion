# 动作片段创建专项复验

适用：v0.4.1 及后续回归。此表为通用空白模板，请在本机副本填写实际结果；不涉及 P5。

从托盘退出旧程序后运行待验证版本。打开现有角色制作副本并准备一张静态图和自己持有的序列帧图集。建议先检查 A01—A08，再检查装饰扩展 D01—D24。

| 编号 | 操作 | 预期 | 实测结果与备注 |
| --- | --- | --- | --- |
| A01 静态创建 | 动作与映射 → 添加动作片段；选静态图片和已导入图片，保留自动编号并添加。 | 不要求填写动画参数；出现原图预览与尺寸。片段加入列表并被选中，既有 idle/映射不变。 | |
| A02 花环创建 | 选序列帧动画、image.ema-border，编号 decoration.ema-border；grid 填 8 列、5 行，按行列推算，200ms、forward，三个选项留空。 | 得到 199×71、40 帧，网格线与单帧可检查；添加、保存后可预览，约 8 秒一轮。 | |
| A03 反向推算和留白 | 重新开窗口，单帧填 199×71，按单帧尺寸推算。再手动将 frameCount 改 39；可用带少量边缘留白图片测试。 | 推算得到 8×5、40；帧数 39 合法，提示只用前 39 格。右/底余量会提示而非拒绝。 | |
| A04 可选布尔值 | 用 4 帧小样，方向 ping-pong；分别试三个选项未指定/false/true，再试 repeatEndpoints 与 returnToStart 同为 true。 | 帧序摘要与制作说明一致，保存再打开保留选项。未指定省略字段，false 不误变 true。 | |
| A05 不规则帧 | 选择 rects，填两行不同宽高且在图内的矩形，再重复其中一行。 | 网格参数隐藏，帧数按行计，滑块能查看各帧；重复帧不被误判为无效。 | |
| A06 错误检查 | 分别输入超过容量的帧数、越界格宽/帧矩形、0/负数/小数列数、0ms；再改正重试。 | 参数检查/添加明确拒绝，指出问题；不向列表写入半成品，也不覆盖原片段；改正后可添加。 | |
| A07 编号与取消 | 输入已有片段编号，尝试添加；改为新编号后取消。另测试关闭窗口及 Esc。 | 重复编号拒绝，无原片段覆盖；取消/关闭不创建片段，不影响已有草稿。 | |
| A08 列表与持久化 | 创建后直接切到前景与背景，给花环选择新片段；保存、停止并重新预览、重启打开项目，再导出并重新导入。 | 新片段即时可选，保存与往返后参数、选项和装饰引用保持；实际动画正常。 | |
| A09 切图与校验期间编辑 | 在窗口快速切换两张不同尺寸的图片，检查尺寸和图是否一致；校验时改参数再添加。 | 旧图片迟到不会替换新图；若校验期间参数变化，会要求重试，不把旧参数当成新参数保存。 | |
| A10 现有功能回归 | 使用旧片段播放回复，测试前后景层级、独立速度、隐藏续播、素材重命名；最后检查未完成项目可创建片段。 | 原装饰和播放行为保持；没有完整角色基础配置也可先创建合法片段，完整包导出仍按原有规则检查。 | |
