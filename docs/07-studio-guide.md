# P4 制作工作台使用说明

P4 使用应用内独立的“制作工作台”页面。角色、声明式规则插件、气泡主题分别保存为制作项目；与日常伙伴实例、聊天、记忆、服务密钥和运行状态分开。制作不要求修改源码或重新构建程序。

## 从单张图片开始

1. 新建角色，在“角色与人格”填写 packageId、版本、名称、对用户的称呼和固定人格。packageId 是作品标识，后续更新保持不变；为不同作品使用不同标识。
2. 在“素材库”添加 PNG/WebP 图片。选择该素材，点击“以此图创建静态待机角色”，再保存编辑。图片应小于或等于 4096×4096；显示时保留纵横比。
3. 在“独立制作预览”点击中文短句、长文和预览按钮，检查基础形态和分页。没有插件也可以导出并运行。
4. 检查完整包，查看文件清单和提示，再导出一个新的 .ayase 文件。程序拒绝覆盖旧导出文件。
5. 回到伙伴页导入，明确选择“创建新伙伴”。导入本身不会安装插件、启用服务或创建记忆。

“保存编辑”保存到本机内部制作区；“项目另存到新文件夹”导出可继续编辑的 project.json、逻辑文件和校验存储。“打开项目文件”创建其内部副本。关闭应用前保存尚未提交的表单编辑。制作项目与分发包用途不同，project.json 不进入分发包。

## 素材与动作

素材库按图片与图集、固定音声、固定文字、其他素材分组，各分类可独立折叠并提供对应导入入口；支持按编号或文件名查找。图片图集显示首帧缩略图，文字展开后显示摘要，音声有独立类型标记。素材编号默认取文件名（去扩展名），可单独填写编号以替换已有素材。支持图片、音声和 UTF-8 文本；音声格式由当前 WebView2 解码能力决定。预览失败会结束相应通道并在状态中说明，不无限占用任务。

先“查看引用”，再重命名或删除。重命名会更新模型、已知配置及主题中的编号；仍有引用的素材不能删除。未知插件可能引用的编号会阻止无法安全确认的修改。替换应保留原编号，并重新检查图集尺寸、动作布局和试听结果。

“动作与映射”把片段选择、预览和停止集中在预览框上方，滚动查看画面时控制栏保持可见。参数支持逐项、逐层折叠，也可全部展开/折叠；同一工作台会话内保留展开状态，折叠不会清除数值。

“动作与映射”支持单图、网格、逐帧矩形，逐帧时间、正放/倒放/往返、偏移、锚点、基础状态和语义映射。也可导入一份完整模型 JSON。模型中 idle 必需，music/quiet 缺失时按既有降级规则处理。基础模式的 enter/exit 是有限片段，loop 为循环；语义动作可复用这些片段。

## 插件配置与制作

角色项目的“插件配置”可以添加内置或已导入的独立插件，公共参数由与控制台相同的 Schema 表单生成。配置可全部跳过。“合并导入预设清单”按 presetId 替换同号项、添加新项，不删除清单外已有项，也不自动安装未知插件。

每份配置可启用/关闭、调整优先级、设置条件和回复。固定与后备变体支持多段文字、顺序音声、语义动作或直接片段编号；同一任务内部不会被其他预览回复插入。短文字仍遵守全局/主题最少阅读时间。状态专用项优先于通用项；缺少匹配项则不回应。高级 JSON 可保留未知字段，但最终仍须通过共享校验。

新建每日提醒插件提供 23:00 模板。在“插件与默认配置”修改插件标识、版本、时间、时区、有效期和回复；在“规则与参数”可编辑协议允许的订阅、条件、动作和公共参数 Schema。声明式规则不支持任意脚本或本机命令。导出 .ayplug 后，可以在工作台导入以添加到角色，也可在伙伴页导入并安装；两者是独立操作。

## 独立预览

保存后选择虚拟时间、idle/music/quiet、大小、事件、环境事实与插件预设，再模拟触发。每次预览从独立模拟运行状态开始，便于重复检查同一事件；不会消耗真实主动互动预算或修改日常伙伴去重记录。显示、音声、动画经过独立 Rust 调度授权，使用与桌宠相同的资源解析、模型、气泡和播放器。

生成回复默认用模拟正文；不访问聊天、TTS、屏幕、搜索和记忆服务。只有主动勾选真实服务并点击插件预览才会使用已保存的聊天配置；语音还要另行勾选。真实预览使用项目人格及当前伙伴的音色/语言设置，不读取或写入伙伴历史、记忆。它可能计费。固定音声试听是本地播放。状态和服务错误留在页面状态中。

项目保存、切换及停止会撤销旧预览；修订号和任务代次阻止旧结果在新项目中播放。预览尺寸仍应在最终桌面、多屏和 DPI 条件下人工确认。

## 主题与气泡

“主题与气泡”控制全局主题；工作台可制作 .aytheme，也能为角色附带推荐主题。导入或切换角色不会自动替换用户主题，需明确点击“采用当前角色推荐主题”。

支持颜色、背景不透明度、圆角、内边距、尾巴、字体、打字机速度、最少阅读时间及 PNG/WebP 九宫格。先导入九宫格图片，再在 backgroundAsset 填素材编号；切片单位为原图像素，左右/上下之和必须小于图片尺寸。主题只允许数据，不执行 CSS、HTML、JavaScript 或网络资源。无效主题无法应用，原主题保留；角色包中损坏的推荐主题只产生提示，不阻止角色运行。

位置偏移使用 Windows 逻辑像素，正值向右/向下。最大宽高为上限，短文字按内容收缩。关闭手动宽高时保持原有随模型变化的限制；手动高度可超过角色，但始终受当前显示范围限制。正负大偏移会在屏幕边缘被约束，无法保证极端数值的完整位移。

输入背景不透明度仅改变独立输入窗口的背景，文字和按钮保持清晰。字体不可用时依次尝试中文字体和系统 sans-serif。九宫格资源不可读时使用纯色背景。主题保存后重启仍保留。

## 更新、恢复推荐值与回退

同 packageId 的新包导入后，点击“更新当前伙伴”先查看三方差异：旧包推荐值、新包推荐值与当前用户配置。未修改的字段可跟随新推荐，用户修改和删除默认保留；冲突逐项显示，勾选后才采用新推荐值。预览后伙伴或配置变化会要求重新预览。

“恢复包推荐值”针对某份原包插件配置清除本地覆盖及删除标记，其他配置不变。回退角色包恢复对应旧包和当时保存的配置；实例 ID、聊天与记忆身份保留。另一个同源实例不受影响。首次 P4 打开已有档案时保留升级前宿主档案备份。

导出始终重新生成完整性清单、验证资源和协议。不包含服务密钥、端点、实例 ID、记忆 bank、历史和运行日志。未知插件配置与原始资源保留；未安装时不执行，安装兼容插件后可继续编辑。角色素材的分发授权仍由作者确认。
