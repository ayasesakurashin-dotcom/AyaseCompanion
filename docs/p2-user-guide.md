# P2 人格、聊天、语音与记忆配置

P2 候选基于已验收的 v0.1.0。先从托盘退出正在运行的旧版本，再启动候选程序。已有伙伴和离线设置继续使用，首次升级会在应用数据目录的 backups 中保存升级前宿主数据库；应用文件与用户数据分别回滚。

## 1. 创建两个独立伙伴

在“伙伴”页从同一角色包创建两个新伙伴，分别改名为测试 A、测试 B。同一角色包可以复用图像与固定音声；人格、音色、插件覆盖、草稿和历史分别属于实例。

“更新当前伙伴”只替换模板引用，保持实例和记忆；“创建新伙伴”生成新的实例和记忆身份。建议所有遗忘实验都使用新建测试伙伴。

## 2. 聊天服务

打开“人格、服务与记忆”页，在“本机服务连接”中启用聊天服务，填写支持 Chat Completions 流式输出的 API 基础地址、模型名称和该服务的 API 密钥。基础地址通常包含 /v1，程序会追加 /chat/completions。填写模型时使用该提供者和账户实际可用的名称。

每个服务有独立“测试连接”按钮，使用当前填写的地址、模型和密钥，无需先保存。测试不会自动保存密钥。聊天测试发送一条短测试提示并检查是否收到正文，不携带伙伴人格、聊天历史或记忆。测试也会使用服务额度。

保存后从桌宠打开独立输入框，选择“与伙伴聊天”并发送一句话。未配置服务时，可在输入框选择“离线固定文字验证”，或使用“播放验证”页。API 错误留在状态区，不会被当作角色台词朗读。

密钥由 Windows 加密保存。空白表示保留当前地址已有密钥；勾选“清除这个地址已保存的密钥”可删除它。更换地址需要为新地址重新填写凭据，不能将密钥放在 URL 中。

## 3. 统一人格与 Fish Audio

在当前伙伴设置中编辑角色称呼、对你的称呼、人格和回复语言，保存后作用于下一条生成回复。聊天、生成问候和生成提醒使用同一份人格。

启用语音服务，接口选择 Fish Audio，基础地址填写 `https://api.fish.audio/v1`，模型填写账户可用的 Fish 模型，并保存 Fish 专用密钥。再为当前伙伴填写音色 ID，勾选“朗读生成回复”。音色属于伙伴，可以为 A、B 绑定不同音色。合成语音是 AI 生成的声音。接口字段见 [Fish 官方说明](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)。

可选 OpenAI 兼容语音接口时，填支持 /audio/speech 的基础地址、语音模型和 voice 名称。该选项使用独立的语音凭据，不自动使用聊天密钥。[接口说明](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)

文字优先：先等模型正文完整生成并整理为可读文本，再排队按气泡偏好的速度呈现；语音另行准备，整条音声就绪后连续播放。音声就绪后开始：额外等待整条音声合成准备完毕，再共同开始呈现；语音不可用时保留文字。两种策略均等待当前整条任务结束才交接。默认发送新消息也是等待，可以在伙伴设置中改为明确停止当前回复。

每条生成文字上限可设置为1—4000字，支持短句回复；这是最大值，不要求每次达到该长度。设得很小时可能截断一句话。

网络接收仍采用流式接口，气泡显示与网络接收分开：完整正文到齐后才开始本地打字动画，分页容量保持稳定。相比逐字转发网络片段，首字出现会更晚；文字优先不必再等音声，音声同步会额外等待合成。音声片段在播放前预缓冲和解码，使用同一音频上下文顺序播放，减少网络和解码造成的段间停顿；声音素材本身的停顿仍会保留。失败、超时、停止和切换伙伴继续按原规则收尾。

模型生成的 Markdown 会转成适合气泡的纯文本：标题、强调、链接标记和代码围栏不会原样显示，保留正文、段落、列表与代码内容。历史显示同样保留段落；旧历史只改变显示，不覆盖保存的原文。用户消息原文不做 Markdown 清洗。

回复语言和朗读翻译目标语言均从下拉列表选择，支持中文、英语、日语等。“朗读翻译目标语言”选择“直接朗读原文”时不进行翻译；选择语言后先翻译再合成，原文仍显示在气泡中。翻译会使用聊天服务，失败会提示并保留文字。旧版本的常用语言别名自动匹配；无法识别的旧值会提示重新选择。

### 连接测试与快捷试听

语音服务的“测试连接”检查账户音色列表接口（Fish）或模型列表接口（OpenAI 兼容）。列表接口可访问不等于当前音色可成功合成；部分兼容服务没有列表接口，此时可用试听直接检查合成。

在“音色与快捷试听”中填写不超过200字的试听原文，点击“合成并试听”。它使用当前填写的语音设置和伙伴音色 ID，按原文合成，不进行朗读翻译、不写入对话历史或记忆。声音通过桌宠正常音声队列播放，当前回复完整结束后才开始。静音时需要先取消静音。点击“停止试听”只取消该伙伴的试听；桌宠的通用“停止”也会撤销准备中的试听。切换伙伴后不播放旧伙伴迟到的音声。

### 从固定音声创建 Fish 音色

1. 在语音服务中选择 Fish Audio，填写可用地址和专用密钥。展开“用当前伙伴的固定音声创建 Fish 音色”。
2. 填写音色名称，勾选当前角色包中的1—5段固定音声。单段最多10 MiB，总计25 MiB。支持 WAV、MP3、FLAC、OGG/Opus、M4A、WebM；服务本身的时长和质量要求仍然适用。
3. 检查每段对应台词。程序尽量从当前有效插件配置读取台词；可以修改，也可以将所有台词全部留空，由服务识别。不可只留空其中一部分。
4. 点击“上传所选素材并创建私有音色”。此操作会将所选音频、对应台词及音色名称发送到当前配置的 Fish 服务，可能使用该服务额度。程序请求 private 可见性和快速创建，不自动上传未选素材。
5. 成功后页面显示 Fish 返回的音色 ID，并保存在发起操作的伙伴下。可以复制 ID，或“填入音色 ID”后保存当前伙伴设置。填入操作本身不自动保存绑定。
6. 音色准备需要时间时，点击“刷新准备状态”，就绪后再试听。创建成功只表示服务返回 ID，听感以实际试听为准。操作中途切换伙伴，结果仍属于原伙伴，切回后可查看；重启后保留创建记录。

程序使用 Fish `/model` 创建及查询接口；默认 TTS 基础地址末尾的 `/v1` 会转换到同一服务的 `/model`，反向代理路径前缀保留。仅提供 TTS 的兼容代理可能不支持创建接口，此时可继续使用已有音色 ID。请求超时或结果未确认时，先在 Fish 控制台核对，避免重复创建。本页不删除远端音色，角色模板导出不包含创建记录或音色绑定。[创建接口](https://docs.fish.audio/api-reference/endpoint/model/create-model)、[状态查询](https://docs.fish.audio/api-reference/endpoint/model/get-model)。

## 4. 固定、生成与明确后备

在行为插件中编辑启动问候或提醒配置的 response：fixed 使用固定变体；generated 填写互动目的；generated-with-fallback 同时填写目的与明确固定后备。生成回复读取当前伙伴人格，插件只描述目的。配置验证不通过时，原有效设置保留。

生成在显示前失败时，只能采用明确配置的固定后备。已经显示一部分后发生断流，会收尾并标记实际呈现部分，不用另一段后备文字替换前文。停止、切换伙伴或遗忘会撤销对应生成；展开输入框、编辑草稿不会打断当前回复。

## 5. 本地上下文与 Hindsight

本地对话和摘要可独立使用。Hindsight 是可选服务，需要单独部署或使用已有远端服务；它自己的模型与存储设置由该服务管理。

### 已有本地 Hindsight

1. 启动服务，确认 API 健康。通用示例：`curl.exe http://127.0.0.1:8888/health`，端口换为你的部署端口。
2. 在本机服务连接中启用 Hindsight，填写 API 根地址，例如 `http://127.0.0.1:8888`。Web 控制台地址仅用于浏览，不填进 API 设置。
3. 服务配置认证时填写对应密钥；本机无认证服务可以留空。程序支持回环地址的 HTTP。
   可以先点击该服务“测试连接”。测试只读 bank 管理列表，不创建、写入或删除记忆。未启用服务端认证时，它只能验证连接，不能判断密钥是否有效；实际 retain/recall 和隔离仍需按后续步骤验证。
4. 为要同步的伙伴勾选“同步此后明确发送的用户消息”，保存后发送不敏感的测试事实。
5. 在摘要与同步状态中查看该伙伴独立 bank 及待同步数量。A、B 应有不同 bank，检索结果和历史应各自独立。

尚未部署时，按 [Hindsight 官方安装指南](https://hindsight.vectorize.io/developer/installation) 选择 Docker 或 Windows 安装方式，配置它使用的 LLM 服务和持久化存储，再完成以上步骤。程序不会自动安装服务器，也不会自动把聊天密钥交给 Hindsight。

### 远端 Hindsight

填写服务提供者给出的 HTTPS API 根地址及该服务凭据，随后按同样步骤为伙伴开启同步。网络、认证和 bank 管理接口需要允许 retain、recall、创建及删除本实例 bank。无需手动填写 bank ID，程序只管理自己生成的命名空间。[retain](https://hindsight.vectorize.io/developer/api/retain) 与 [recall](https://hindsight.vectorize.io/developer/api/recall) 接口说明。

远端离线时，本地聊天和上下文继续使用，待同步保存在本机，恢复后重试。切换服务地址时，旧待办保留原地址与对应凭据，不自动迁移旧记忆。

### 摘要、清空与遗忘

- 摘要只在积累足够历史后整理，长度有上限，原文保留。失败不推进摘要水位。
- 仅清空本地历史：清空当前伙伴历史和摘要，远端长期记忆保留。
- 遗忘本地与远端记忆：取消关联生成，立即切换到新记忆空间，旧远端空间删除排队执行；离线时保留待办，服务恢复后完成。

AI 主动问候、助手猜测和其他外部材料不会自动被当作真实用户事实同步。不要对已有重要伙伴进行破坏性遗忘测试。

## 6. 覆盖编辑与导出

当前伙伴可单独停用固定音声素材，后续任务生效，其他同源伙伴不受影响。导出保存停用状态、有效人格和插件配置，同时保留原始素材与未知插件条目，以保护未知引用。导入导出包后选择“创建新伙伴”，它应获得新历史与新 bank。

导出不带服务设置、密钥、本机音色绑定、历史、摘要或 bank。导出的人格和称呼属于可分发内容，请在分享前检查。完整制作工作台与素材引用冲突编辑属于 P4。
