# 装饰淡变与整体预览专项复验

适用：v0.4.1 装饰扩展及后续回归。本文件为通用空白清单，实测结果只填写在本机候选目录的副本中。

## 准备

退出旧候选程序，运行本轮候选中的 `AyaseCompanion.exe`。继续使用原制作项目与伙伴即可。保持真实服务关闭；准备带通用花环、idle/quiet 背景及 music 背景的角色。

本轮只需检查下面的变更范围。整体预览重新启动会重置动画，启动时直接显示当前状态组合；观察淡入淡出需在已经运行的场景中改变显示条件。

| 编号 | 操作 | 预期 | 实测结果与备注 |
| --- | --- | --- | --- |
| B01 各角色制作页入口 | 依次打开角色与人格、素材库、动作与映射、前景与背景、插件配置、推荐气泡主题。 | 每页独立制作预览顶部都有“保存并开始整体预览”；点击即显示主体和装饰，无须先触发回复。动作页仍可独立预览所选片段。 | |
| B02 保存后预览 | 在角色称呼或主题参数中做一项修改，直接点击整体预览；重开制作项目检查。 | 先保存当前项目草稿再预览，状态显示“已保存”；修改保留。停止制作预览立即清空，重新开始正常。新建但未配置完整的角色仍给出明确校验提示。 | |
| B03 独立插件与主题 | 打开独立插件，在各页点击整体预览；事件选不匹配项、模拟时间清空后再次点击。独立主题也在两页分别点击。 | 有完整合法项目时显示占位角色，不要求插件触发成功，不生成文字/音声任务，不调用真实服务。显式点击插件模拟仍按原有条件判定。主题气泡仍使用文字预览查看。 | |
| B04 D11 状态淡变 | 桌面启动/停止媒体，进入/退出全屏，观察 idle/music/quiet 背景切换；另在带长文字和动作的回复期间操作。 | 已应用基础状态更新后，旧层约 200ms 淡出、新层约 200ms 淡入；全状态花环和主体不一起变淡，原文字/音声/动作继续。 | |
| B05 开关与续播 | 在工作台已开始整体预览时关闭花环，等 5 秒再打开；日常伙伴开关也测试。在工作台改变正在显示层的适用状态。 | 显示变化有淡变；隐藏立即暂停该层动画，恢复后从暂停处续播；不从头播放，不在隐藏期间快进，其他层继续。 | |
| B06 快速反向与边缘 | 在同一连续预览中快速开关同一层，再让装饰明显超出主体左右/下方，关闭后重新打开。 | 反向淡变从当前透明度继续，无闪白或突然全亮；淡出结束前不会因收缩画布而切掉尾部。主体位置、气泡定位和点击范围不因淡变而改变。 | |
| B07 初始化与释放 | 模拟基础状态选 music 后开始整体预览；反复停止/开始，再切换项目或伙伴。 | 初始化直接显示所选状态组合，不先闪现 idle 专用背景；停止和切换立即清理旧画面，没有旧层迟到出现。 | |
