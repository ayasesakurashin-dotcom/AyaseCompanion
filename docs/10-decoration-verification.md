# 角色装饰扩展专项实机验收

适用：v0.4.1 装饰扩展及后续回归。当前已验收基线：v0.4.1。本轮不包含 P5。此文件为通用空白模板，不代表测试已经通过；请在候选目录的副本内填写结果、备注和证据。

## 准备

1. 从托盘退出原程序，运行候选目录内的 `AyaseCompanion.exe`，不要同时运行两个版本。现有伙伴配置继续使用；制作练习导入为新伙伴，原伙伴与制作项目保留。
2. 打开 `Ema-装饰制作素材/05-制作操作说明.md`。先用基础包手动制作；完成示例包用于对照。真实 AI 服务不影响本轮验收，工作台保持模拟服务即可。
3. 日常开关位于“伙伴”页；完整编辑位于“制作工作台 → 前景与背景”。预览按钮为“保存并开始整体预览”。模拟状态位于预览下方的“文字、插件与模拟条件”。
4. 修改位置、大小、顺序、速度和装饰开关后，已开始的工作台预览自动刷新；点击“保存编辑”才持久化。不必为了刷新几何参数反复重新开始预览。重新开始、切换项目和重启都会从头播放动画。
5. 记录显示器数量、分辨率与 Windows 缩放；没有第二台显示器的项目可注明“单屏通过，多屏未测”，不要把未测写成通过。

## 完整检查表

| D07 独立时间与回复 | 两个花环速度分别设 0.5、2；播放包含招手、固定音声、长文字的回复，再提交另一条回复。 | 速度互不影响；新回复、分页、有限动作结束不重置花环；整条回复完成后下一任务正常开始。 | |
| D08 定位和比例 | 依次切换中心、底部和 feet 锚点；测试偏移 +30/-30、自身对齐点、单独宽度、同时宽高、锁定/解除比例及缩放。播放动作对照位置。 | 正偏移向右/下；随整体缩放，主体透明轮廓改变不会造成装饰漂移；变更参数不缩小主体。 | |
| D09 拖动、缩放、DPI | 拖动主体到不同位置，试 60%、100%、160% 显示大小；有多屏时在不同缩放显示器间移动。 | 主体与全部装饰绑定移动，比例、相对位置与层级稳定；没有某层留在旧位置。 | |
| D10 同窗口关系 | 打开、切换、最大化其他普通应用；切回桌宠。用当前程序提供的显示/关闭窗口操作观察整体（退出重启另测）。 | 没有角色在应用前而某个装饰单独被压在后面的分离现象；整个窗口遵循原有窗口策略。系统安全桌面/独占全屏不等同普通窗口。 | |
| D11 状态组合 | 花环设通用，粉色背景设 idle+quiet，蓝色背景设 music；再增加一层取消通用且不选任何状态。分别模拟三个基础状态；在持续运行场景中改变装饰开关/适用状态，或在桌面启动/停止媒体。 | 通用层与专用层同时存在；粉/蓝按状态替换，已有层显示变化约 200ms 淡入淡出；空状态层始终不显示。重新启动整个预览直接显示当前组合。 | |
| D12 过渡与当前回复 | 实际启动/停止媒体，进入/退出全屏；另在播放带长文字和动作的回复期间重复。查看运行记录的已应用基础状态。 | 装饰跟随已应用状态，过渡提交前保留原组合；不提前跟随等待目标，不取消正在播放的文字、声音或动作。 | |
| D13 隐藏暂停续播 | 工作台整体预览开始后，在播放到易辨认帧时关闭某花环，等待 5 秒再打开，不重新启动预览；再通过适用状态隐藏/恢复；日常伙伴开关也测试。 | 被隐藏层从暂停位置继续，不跳到首帧或在后台快进；其他可见层和主体不中断。同状态快照更新不重置。 | |

| D16 气泡与工具条 | 在相同主体位置下，开关装饰并播放短句、长文；让较大的前景靠近气泡和按钮。 | 气泡继续以主体为参照，没有因图层大小跳位；按钮与气泡在合成画面上方；分页、最少阅读时间和末页关闭正常。 | |
