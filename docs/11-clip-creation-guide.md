# 动作片段创建说明

适用：v0.4.1 及后续兼容版本。本功能补齐制作流程，不启动 P5。

## 创建入口

1. 在制作工作台打开角色项目，到素材库导入 PNG/WebP 图片或图集。
2. 进入“动作与映射”，点击“添加动作片段”。
3. 选择片段类型与图片。程序自动生成不与已有片段重复的编号；作者可按需要改成 `decoration.ema-border` 等编号。
4. 检查后点击“添加到动画片段”。新片段加入项目草稿并成为当前选中片段，不覆盖既有片段。
5. 点击“保存编辑”，再点“预览所选片段”核对完整动作。在“前景与背景”选择动画片段来源时也能直接选到新片段。

添加片段不会自动修改主体 idle、其他基础状态或语义动作映射。新建空角色时，如需该片段作为常规形态，应另将 idle.loop 指向它；装饰片段不应替换主体 idle。

## 静态图片

类型选“静态图片”，只需选择素材库图片，编号可保留自动值。内部使用 single 布局、正向和 1000 毫秒的单帧时长；界面不要求填写这些动画参数。用于常驻层时持续显示，用于有限动作预览时单帧显示结束后正常交接。

## 规则网格动画

类型选“序列帧动画”，布局选“规则网格（grid）”。

| 参数 | 含义 |
| --- | --- |
| columns / rows | 图集中每行的列数与总行数，均为正整数 |
| cellWidth / cellHeight | 单格原图像素宽高，均为正整数 |
| frameCount | 从左到右、从上到下使用的前多少格；可小于网格容量 |
| frameDurationMs | 每帧显示的毫秒数，16—60000；默认 200 |
| direction | forward 正向、reverse 反向、ping-pong 往返 |

可用两种推算方式：

- 已知行列：填写 columns/rows，点击“按行列推算格宽、高及帧数”。
- 已知单帧尺寸：填写 cellWidth/cellHeight，点击“按单帧宽高推算行列及帧数”。

推算使用整数尺寸，余下的右侧/底部像素会明确提示。默认把网格容量填为帧数，末行未满时作者应减少 frameCount。推算超过现有 4096 帧预算时不给出截断结果，改为提示手工调整。默认从原图左上角开始，无额外的单格间距；带外边距、格间距或不规则布局请用逐帧矩形。

Ema 花环原图 1592×355；已知 8 列、5 行后可确定每格 199×71、共 40 帧。图片尺寸本身不能唯一说明它一定是 8×5，因而不会未经确认就把某个分割方案当成正确动画。

## 往返选项

三个选项位于“往返播放选项”折叠区，仅在 direction=ping-pong 时有效。

| 选项 | true 的作用 | 未指定/false |
| --- | --- | --- |
| repeatEndpoints | 转向时重复显示端点，返回序列也包含起点 | 不重复端点 |
| returnToStart | 不重复远端，并让单轮末尾回到起始帧 | 采用不额外回到起点的默认往返序列 |
| startReverse | 从最后一帧反向起步 | 从第一帧正向起步 |

未指定（界面中的 null）在保存时省略字段，等效不启用，与原有包格式兼容；明确选择 false 时保留 false。repeatEndpoints 和 returnToStart 同为 true 时，前者已经包含返回起点，不再额外追加。方向改为 forward/reverse 后仍保留选择，但提示这些往返选项不生效。

以四帧为例：默认往返为 1→2→3→4→3→2；returnToStart 为 1→2→3→4→3→2→1；repeatEndpoints 为 1→2→3→4→4→3→2→1。窗口显示当前帧序摘要与单轮时间。

## 逐帧矩形动画

布局选“逐帧矩形（rects）”，每行输入 `x, y, width, height`，坐标以原图左上角为原点。允许帧大小不同、留白、相交或重复引用同一区域，显示顺序由行顺序决定。该布局使用 frames，因此不再填写网格的 columns/rows/cellWidth/cellHeight；帧数由行数确定。

## 自动检查能做到什么

图片加载后显示实际宽高。“图片与切片边界”展示每帧范围，“检查源帧”滑块可以逐帧查看裁切结果。这是静态切帧检查，完整播放继续使用工作台正式预览，不调用大模型或远端服务。

可以客观拒绝：图片不可读或未选择图片、零/负/非整数网格参数、切片越界、帧数超过容量、非法方向、时间超限、重复编号。创建时还会由宿主读取项目中真实图片，使用与包导入相同的帧布局校验，不能只凭前端尺寸通过。

合法但需作者确认：图片边缘有余量、最后一些格不用、逐帧矩形重复或相交、某帧完全透明、帧序中有停顿。只要满足资源和几何规则，就不会因“看起来不像动画”而拒绝。

无法仅凭尺寸保证：分割线是否恰好对齐美术帧、是否切到角色、帧序/速度是否符合设计、画面是否连贯。不使用大模型也能做启发式猜测，但空白边界、透明留白与多种网格方案都有歧义，本轮采用作者指定一组已知信息再推算的方式。
